Ashkiln builds native desktop trading tools for the Solana ecosystem.

## Ashkiln Pumpfun Launcher

Multi-wallet token launcher for pump.fun with atomic Jito bundling and
automated market-cap-triggered sell ladders.

- Launch across multiple wallets in a single atomic bundle
- HD wallet derivation from a BIP-39 phrase, AES-256-GCM encrypted at rest
- Take-profit and stop-loss ladders that trigger on live market cap
- Windows desktop binary, no runtime dependencies
